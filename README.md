# classm-killer

**2024년에 개발한 프로그램으로 현재 동작 유무는 확인되지 않았습니다.**

이 프로그램은 학생 관리 프로그램인 classm을 차단하기 위해 개발되었습니다.

본 프로그램은 담당 선생님의 허락 하에 개인적인 취미 활동 및 학습 목적으로 개발한 프로그램입니다.

프로그램의 동작이나 사용 방식에 문제가 있다고 판단되거나, 학교 관련 기관의 요청이 있는 경우 프로그램의 배포를 즉시 중단하고 관련 파일을 삭제할 수 있습니다.

본 프로그램은 상업적 목적이 아닌 개인적인 학습 및 취미 개발을 목적으로 제작되었습니다.

## 사용상 주의 및 책임 고지

Windows 환경에서 지정된 프로세스를 **관리자 권한으로 강제 종료하고, 종료 작업을 무한 반복하는 배치 스크립트**입니다.

본 프로그램은 지정된 프로세스를 강제로 종료하는 기능을 포함하고 있으며, 관리자 권한을 요구하고 종료 작업을 반복적으로 수행합니다. 따라서 사용 전 대상 프로세스와 프로그램의 동작을 충분히 확인하시기 바랍니다.

강제 종료로 인해 작업 중인 데이터의 손실, 프로그램 오류, 파일 손상, 서비스 중단 또는 시스템 불안정 등의 문제가 발생할 수 있습니다.

본 프로그램은 사용자의 판단과 책임하에 사용해야 하며, 사용 전에 중요한 데이터와 작업 내용을 반드시 저장하시기 바랍니다.

사용자는 본 프로그램의 사용으로 인해 발생할 수 있는 모든 문제와 그 결과에 대해 충분히 주의하고, 자신의 판단과 책임하에 사용해야 합니다. 본 프로그램의 제작자는 사용자의 부주의, 잘못된 사용 또는 사용 환경으로 인해 발생한 데이터 손실 및 기타 직·간접적인 피해에 대해 책임을 지지 않습니다.

## 동작 개요

스크립트는 다음 순서로 동작합니다.

1. 현재 프로세스가 관리자 권한으로 실행되고 있는지 확인합니다.
2. 관리자 권한이 없으면 Windows UAC를 통해 관리자 권한으로 스크립트를 다시 실행합니다.
3. 스크립트가 위치한 디렉터리로 작업 경로를 변경합니다.
4. 아래 프로세스를 강제 종료합니다.
5. `goto A`를 이용해 4번 과정을 **무한 반복**합니다.

## 종료 대상 프로세스

| 프로세스                        | 설명                     |
| --------------------------- | ---------------------- |
| `ClassM_Client.exe`         | ClassM Client 관련 프로세스  |
| `ClassM_Client_Service.exe` | ClassM Client 서비스 프로세스 |
| `SysCtrl.exe`               | 시스템 제어 관련 프로세스         |
| `mvnc.exe`                  | 지정된 프로그램 구성 요소         |
| `hscagent.exe`              | HSC Agent 관련 프로세스      |
| `hscdm.exe`                 | HSC 관련 프로세스            |
| `hscfm.exe`                 | HSC 관련 프로세스            |
| `hscrelay.exe`              | HSC Relay 관련 프로세스      |

프로세스 이름은 스크립트에 지정된 값 그대로 사용되며, 실제 프로그램의 역할은 설치 환경이나 소프트웨어 버전에 따라 다를 수 있습니다.

## 관리자 권한 확인

다음 명령을 사용하여 관리자 권한 여부를 확인합니다.

```bat
cacls.exe "%SYSTEMROOT%\system32\config\system"
```

명령 실행 결과의 `errorlevel`을 확인하여 관리자 권한이 없으면 UAC 요청 단계로 이동합니다.

## UAC 관리자 권한 요청

관리자 권한이 없는 경우 임시 VBScript 파일을 생성하고 `Shell.Application`의 `ShellExecute`를 사용하여 현재 배치 파일을 `runas` 동작으로 다시 실행합니다.

```bat
Set UAC = CreateObject("Shell.Application")
UAC.ShellExecute "%~s0", "", "", "runas", 1
```

관리자 권한으로 재실행된 뒤 임시 `.vbs` 파일은 삭제됩니다.

## 프로세스 강제 종료

각 프로세스는 다음과 같은 방식으로 종료됩니다.

```bat
taskkill /F /im ClassM_Client.exe
```

여기서:

* `/F` : 프로세스를 강제로 종료
* `/im` : 이미지 이름(프로세스 이름)으로 대상 지정

따라서 저장되지 않은 작업이 있는 프로그램도 정상 종료 과정 없이 종료될 수 있습니다.

## 무한 반복

스크립트 마지막의 다음 구문 때문에 종료 작업은 계속 반복됩니다.

```bat
goto A
```

즉, 스크립트 자체를 중지하기 전까지 지정된 프로세스에 대한 `taskkill` 명령이 반복적으로 실행됩니다.

## 실행 방법

1. 내용을 `*.bat` 파일로 저장합니다.
   예:

```text
BatchGotAdmin.bat
```

2. 배치 파일을 실행합니다.
3. 관리자 권한 요청 창(UAC)이 표시되면 허용합니다.
4. 지정된 프로세스가 실행 중인 경우 강제로 종료됩니다.
5. 스크립트는 프로세스 종료 명령을 계속 반복합니다.

## 스크립트 중지 방법

무한 반복 구조이므로 일반적으로 다음 방법으로 중지할 수 있습니다.

* 콘솔 창에서 `Ctrl + C`
* 배치 파일 실행 창을 닫기

필요한 경우 작업 관리자에서 해당 `cmd.exe` 프로세스를 종료할 수도 있습니다.

## 동작상의 특징

이 스크립트는 단순히 한 번 프로세스를 종료하는 것이 아니라 **프로세스가 다시 실행되는 경우에도 반복적으로 종료를 시도**합니다.

`ClassM`의 경우 `ClassM_Client.exe`, `ClassM_Client_Service.exe` 등 관련 프로그램들이 한 프로그램이 종료되면 다른 프로그램이 종료된 프로그램을 재실행하는 방법으로 동작합니다. 이때 재실행시 와이파이 차단, 화면 잠금 등이 적용되는 시간보다 `taskkill` 명령어로 다른 프로그램을 종료하는 시간이 짧아 `ClassM`을 무력화 시킬 수 있습니다.

이 프로그램을 변형 시 다음과 같은 용도로 사용할 수 있습니다.

* 특정 프로그램의 실행을 일시적으로 차단
* 자동 재실행되는 특정 프로세스의 반복 종료
* 테스트 환경에서 특정 프로세스 종료 상태 유지

### CPU 사용량

`goto A`를 통해 쉬지 않고 명령을 반복하므로 콘솔 및 시스템 자원을 불필요하게 사용할 수 있습니다. 대상 프로세스가 존재하지 않는 경우에도 `taskkill` 명령이 계속 실행됩니다.

2024년 당시 테스트 결과 몇 분 이상 동작시키면 `ClassM`이 더 이상 재실행 되지 않았습니다.
따라서 프로그램 실행 후 특정시간이 지난 후에는 cpu 사용량 감소를 위해 프로그램을 종료하는 것을 권장드립니다.

## 원본 코드의 구조

핵심 구조는 다음과 같습니다.

```bat
@echo off

:A
mode 1000

taskkill /F /im ClassM_Client.exe
taskkill /F /im ClassM_Client_Service.exe
taskkill /F /im SysCtrl.exe
taskkill /F /im mvnc.exe
taskkill /F /im hscagent.exe
taskkill /F /im hscdm.exe
taskkill /F /im hscfm.exe
taskkill /F /im hscrelay.exe

goto A
```
